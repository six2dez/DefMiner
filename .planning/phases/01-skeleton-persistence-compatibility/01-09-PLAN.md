Close UAT gap 2: give CORE-01's no-outbound-traffic prohibition teeth.

The prohibition is authored descriptor-less in plan 01-01, which correctly disposes
`{status: unverified, flagged: true}` — but nothing enforces it. The verifier's own evidence says so:

that most needs enforcement, and it is the one with none. Three measured facts from Phase 0 make a
regression here worse than it sounds. `SURFACES_FIRING_INTERCEPT = "proxy"`: plugin-originated sends
do not come back through `onInterceptResponse`, so traffic this plugin generated would be invisible to
this plugin's own counters — there would be no number anywhere that moved. `sdk.requests.send()` does
not re-fire the hook under any save/plugins combination, so there is no self-observation to fall back
on. And `caido/caido#2211` was filed against 0.57.1, the exact target build: cumulative sends can
abort `caido-cli` outright, taking the operator's real project data with it.

Output: an AST gate over `packages/backend/src`, shaped like the two that already work in this
repository, with a violating fixture for every rule and a mutation run against the real tree.

over already-shipped code; there is no path through the stack to wire and nothing end-to-end to prove.

`files_modified` overlap with 01-07 and 01-08 is genuinely zero — verified pairwise — so the wave
guard would have allowed all three side by side. The coupling is one axis over, and the wave guard
