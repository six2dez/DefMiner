Purpose. `let r; r ??= sdk.requests; r.send(req)` reports nothing, and `let r; r = sdk.requests;
r.send(req)` reports `outbound-send`. The difference between the reported form and the silent one is
two characters, and `r ??= sdk.requests` is the ordinary lazy-init spelling of the line directly above
it. Nine shapes are silent — across `??=`, `||=` and `&&=`, on `sdk.requests`, `globalThis`, `fetch`,
`eval`, `navigator`, a string key and an assembled key — and **all four `=`/`+=` controls fire**, which
is what makes this a measured finding rather than a guess.

**The file already knows the shape exists.** `collect`'s alias-growing branch is gated on a single
token comparison against the plain-assignment operator. Eleven lines below, in the same function, the
numeric-POISONING arm reads `ASSIGNMENT_OPERATORS`, excludes the numeric compounds, and carries a
comment naming the exact expression `x ||= sdk.requests`. So the declared set already exists, the
motivating example is already written down, and the walk already reacts to the shape — **by removing a
numeric exemption, and by doing nothing else.** That is the reporting side of this file's own
reported-versus-followed distinction, which is the argument CR-10 was raised on and closed on.

`assembledNames`' clause names `a compound assignment` outright, and `??=` is a compound assignment
that grows nothing. `receiverAliases`, `constStrings`, `literalsOf`, `globalThisAliases`,
`fetchAliases`, `navigatorAliases` and `globalAliases` each say a name BOUND to the surface IS that
surface. `r` is bound to `sdk.requests` in the file and is a receiver nowhere in it. No MEASURED
SILENCE row names a logical assignment: it is one hop, in this file, not a parameter, not a loop

granularity: the operator set gains three members, and each one gets its own executed probe.

for `&&` by measurement. It is stated as a decision with its measurement rather than assumed by
