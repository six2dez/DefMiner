<objective>
Prove the entire Phase 1 architecture end-to-end on a real Caido, in one commit, before any layer is built out.

A JavaScript response is proxied through an isolated live Caido 0.57.1 instance. The non-async
`onInterceptResponse` hook gates it cheaply and enqueues an id. Exactly one consumer drains the queue,
reloads the work with `sdk.requests.get(id)`, takes `toRaw()` bytes, hashes them with native SHA-256, and
writes one single-statement idempotent upsert keyed on `(project_id, sha256)`. The row is then read back
over an RPC and its digest compared against a SHA-256 the host computed independently of Caido.

Purpose: every architectural risk in this phase lives on that one path, and three of them can only be
answered by running it. `ON CONFLICT ... DO UPDATE` needs SQLite >= 3.24 and `SELECT sqlite_version()` has
never been executed behind `sdk.meta.db()` (RESEARCH.md Open Question 1, confidence LOW, **no fallback**).
No probe in this repo has ever called `sdk.requests.get(id)`, so the reload model, its `undefined` branch
and its behaviour after a queue delay are entirely unexercised (Open Question 2). And the built bundle's
import specifiers must resolve inside Caido's QuickJS, which the build cannot tell you. Answering all
three after one commit costs one commit; answering them after ten costs ten.

Output: a working vertical slice, a live end-to-end verification script, and a committed
`runtime-answers.json` recording the measured answers to Open Questions 1 and 2.

**Two sizing decisions, recorded rather than hidden.** This plan is the heaviest in the phase and sits near
the top of the smart-zone budget on a `confidence: low` estimate (no calibration history exists yet —
`estimate-calibration` reports `sample_count: 0`), so where the work sits matters. First, the threshold
contract's four GATES were moved out of the tracer task into task 3: the generator, the generated file and
`thresholds.ts` stay on the tracer's path because the admission ceiling and the queue cap are imported from
them, but authoring the regeneration-drift harness is the single heaviest piece of test work here and has no
bearing on whether the vertical slice works. Second, the contract was NOT split into a separate wave-1 plan:
a config-constants plan running beside the tracer is "configuration first" wearing a parallelism costume, and
it would put a second writer on `vitest.config.ts`. The residual risk is accepted and named: if the executor
degrades anywhere in this plan, it will be in the second half of the tracer task, and the end-to-end
`<verify>` is what catches that rather than a reviewer's eye.

**Deliberate deviation from the >5-files split rule.** A tracer touches one file per layer, and this phase
has six layers plus its build and threshold config. Every file here is small — the production analog
(`probe/recorder/backend/script.js`) implements most of this slice in 142 lines and has been running
against the operator's real traffic for days. Splitting the slice by layer would reintroduce exactly the
horizontal decomposition tracer-first exists to prevent.
</objective>

- **STORE-03 (unclassified)** — assumed: "content-addressed by digest" means the artifact's identity is
  `(project_id, sha256)` and URL is an attribute of an *observation*, not part of artifact identity. The
  same bytes served from two URLs is one artifact with two observations.

  <context>

    databases.

    unusable on the pooled connection, so a surrogate `id` primary key is a row identity you can never
    read back. And `BEGIN` does not span `exec` calls while every statement still returns SUCCESS, so no
    invariant may require two statements to land together — every write must be a single-statement
    idempotent upsert on a key you already hold.

| Boundary | Description |
|----------|-------------|
| target origin -> Caido proxy -> `onInterceptResponse` | Every byte, header and URL crossing here is target-controlled and fully untrusted |
| plugin process -> `sdk.meta.db()` | Untrusted strings (URL, content type) become SQL bind values in a plugin-global database shared across every project |
| plugin process -> `sdk.console.log` -> host log | Untrusted bytes can reach a durable log the operator reads |
| test harness -> isolated `caido-cli` instance | A guest-token instance that trusts any caller; must never bind beyond loopback or collide with the operator's live instances |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Denial of Service | `packages/backend/src/hooks/passive.ts` admission gate | critical | mitigate | Reject on `body.length` above `PASSIVE_MAX_BYTES` BEFORE any `toRaw()` or decode. Caido's QuickJS sets no memory limit and runs under `panic = "abort"`, so an OOM kills `caido-cli` with the operator's project data; at the measured 102.112 RSS bytes per input byte the ceiling is asserted to project under 1 GiB by `thresholds.spec.ts`. |
| T-01-02 | Information Disclosure | `packages/backend/src/store/{artifacts,observations}.ts` schema | high | mitigate | Neither v1 table has a column able to hold body bytes, headers, cookies or a secret value. Raw bytes are hashed into a local and go out of scope; nothing is persisted. `observations.url` is the one target-influenced string that IS stored, deliberately and minimally — fragment stripped, query kept because it is what distinguishes a cache miss, `content_type` truncated. Enforced by absence and by plan 01-04's column-allowlist schema test. |
| T-01-03 | Tampering | `packages/backend/src/store/artifacts.ts` SQL | high | mitigate | Positional `?` binding only, via `prepare()` then `run(...spread)`. No target-controlled string is ever concatenated into a SQL literal. `exec()` is used for `IF NOT EXISTS` DDL only. |
| T-01-04 | Information Disclosure | `packages/backend/src/index.ts` and `ingest/consumer.ts` logging | medium | mitigate | Log lines carry request ids, byte lengths and error strings truncated to 200 characters. No body bytes, no `toText()` of an artifact, no header values reach a log line. |
| T-01-05 | Elevation of Privilege | `scripts/phase1/tracer-e2e.sh` test instance | medium | mitigate | Reuse `scripts/spike/instance.sh` unchanged: binds `127.0.0.1` only, `--allow-guests` with `--no-sync`, isolated `--data-path`, port asserted free before launch, guest token written at umask 077 and deleted on teardown, teardown always SIGKILL. |
| T-01-06 | Denial of Service | live SPIKE-10 recorder on 127.0.0.1:8998 and desktop Caido on 8080 | high | mitigate | `scripts/phase1/env.sh` allocates 8971/8972, outside every port Phase 0 or the operator owns. `instance.sh` refuses 8080 unconditionally and refuses any port already in LISTEN, and never kills a process it did not start. No Phase 1 script reads or writes `.spike/`. |
| T-01-07 | Denial of Service | `packages/engine/src/queue.ts` | medium | mitigate | Bounded ring at `QUEUE_CAP` with drop-oldest and a monotonic overflow counter. Caido queues generously and loses nothing, so back-pressure is ours to impose; an unbounded array would be our failure, not one Caido protects us from. |
| T-01-08 | Repudiation | `packages/engine/src/thresholds.generated.ts` | medium | mitigate | Generated, not authored. `thresholds.spec.ts` regenerates and asserts byte-equality, so a constant tuned to make a test pass fails CI rather than silently redefining a measured budget. |
