## Debts discharged in this plan, in its own words

**UI-SPEC Named Conflict 2 — the fifth vocabulary-separation mechanism breaks.** The Phase 5/6 rule is
that no surface renders both closed state vocabularies. The drill-down renders the parent artifact's
analysis state and each recovered source's producibility in the same view, and there is no arrangement
of D-21's drill-down in which that is false — and there should not be, because the analysis state is
the context that explains an empty source list. The mechanism is therefore **REPLACED, NOT EXEMPTED**,
by four binding requirements: different regions, different levels, a testable no-shared-subtree rule
asserted in both directions, a SENTENCE rather than a badge for the degraded case, and NOTHING AT ALL
for the common case. **The other four mechanisms transfer unchanged and are not weakened.** The O-07
pre-emption paragraph this conflict also owes is recorded in plan 07-04 and carried into
`07-VERIFICATION.md`.

**Where each of the four requirements is settled:** requirements 1 and 2 are asserted HERE, over the
fully rendered drill-down with the evidence panel mounted and a tombstoned source selected, because
they need both regions on screen at once. Requirement 3 — a SENTENCE rather than a badge for the
degraded case — is a property of the viewer body and is asserted in plan 07-08. Requirement 4 —
NOTHING AT ALL for the common case — follows from plan 07-07's presentation map, which renders no mark
for the producible state. No requirement is asserted twice and none is unowned.
