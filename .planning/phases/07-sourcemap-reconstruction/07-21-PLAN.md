<objective>
Put a relative loader-query label into the measured corpus, and absorb the ripple that adding one
deliberately costs.

This is the FIRST half of **G-07-3 / WR-03**, and the gap's own `missing` list says so: *"Add a
relative `?` corpus case FIRST — it pins whichever direction is chosen and is worth doing regardless."*
`SOURCES_LABEL_CASES` holds 23 entries and NOT ONE contains a `?`, so `export.spec.ts`'s corpus passes
identically in redacted and raw mode and 07-16's narrowing is untested in the direction that changed.
The premise the narrowing rests on — `export.ts:255-256`, "a label that is not a URL has neither axis"
— is falsified by the ordinary vite/webpack shape `src/App.vue?vue&type=script&lang.ts`, which
`classify()` puts in `relative`.

The corpus is deliberately expensive to extend. `map-fixture.ts` says so in its own words: the id
arrays exist so that "adding a case here fail every consumer until each one accounts for it, which is
the intended cost". Nine spec files read the corpus and three of them state its size as a literal,
one of those in a PRODUCTION comment. Absorbing that ripple honestly — authoring the expectation for
the new label at every site rather than loosening any assertion — is most of this plan's work and is
the reason it is its own plan.

**This plan does not decide the redaction direction and must not.** Plan 07-22 owns that decision at a
blocking checkpoint. What this plan delivers is the case that makes either direction pinnable, plus one
honest disclosure for whoever reads the tree between the two plans: at the end of this plan
`export.spec.ts:909`'s test title — which says none of the corpus labels has a query axis — is a FALSE
STATEMENT that its assertion nonetheless still satisfies, because the shipped code returns a
non-protocol label verbatim in both modes. That sentence is 07-22's to correct. It is named here so it
is not read as new drift.

Output: a 24-case corpus, five corrected counts, and nine consumers that pass because they exercise
the new label rather than because they stopped looking.
</objective>
