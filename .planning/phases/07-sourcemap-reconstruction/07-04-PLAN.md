<objective>
Give recovered source a place to be REMEMBERED without ever being STORED.

D-05's identity model is the shipped `artifacts` / `observations` split applied to a second entity
class. D-07 means the content itself is never held: the tables carry a name, a size, a content hash,
which map it came from and which request produced it — and nothing else. That is not a compromise, it
is the phase's strongest security property: recovered source is the target's actual source code,
plausibly containing credentials, internal hostnames and business logic, and a stolen copy of the
plugin database contains none of it.

This plan also settles O-07 by declaring the third closed vocabulary, and takes the fourth one-way
operator checkpoint on `EXPECTED_TABLES` — three prior approvals are named in that array's own doc
comment and this one joins them.

Purpose: MAP-06's once-per-content-hash guarantee becomes literal, and the drill-down gets something
to read.
Output: migration `v: 8`, two tables, one new closed vocabulary, `store/sources.ts`, and one paged
read.
</objective>

**The proposal, stated in full before the migration is written.**

Two tables, alphabetically placed, giving `EXPECTED_TABLES` eight members:
`["analyses", "artifacts", "audit", "observations", "scans", "settings", "source_sightings", "sources"]`

**`sources`** — content-addressed identity, one row per distinct recovered source CONTENT:

| Column | Type | Why |
|--------|------|-----|
| `project_id` | `TEXT NOT NULL CHECK (length(project_id) > 0)` | STORE-02; PK ordinal 1 |
| `source_sha256` | `TEXT NOT NULL CHECK (length(source_sha256) = 64)` | D-05's identity. PK ordinal 2 |
| `byte_len` | `INTEGER NOT NULL` | DefMiner-computed size, for the tree and the manifest |
| `line_count` | `INTEGER NOT NULL` | DefMiner-computed; lets the viewer state a line count and the O-02 no-line-structure case be detected without re-deriving content |
| `first_seen_at` | `INTEGER NOT NULL` | Retention ordering |

PRIMARY KEY `(project_id, source_sha256)`.

**`source_sightings`** — one row per `(map, index)` sighting:

| Column | Type | Why |
|--------|------|-----|
| `project_id` | `TEXT NOT NULL CHECK (length(project_id) > 0)` | STORE-02; PK ordinal 1 |
| `map_sha256` | `TEXT NOT NULL CHECK (length(map_sha256) = 64)` | The decoded map's digest. PK ordinal 2 |
| `source_index` | `INTEGER NOT NULL` | The index into the map's `sources` array. PK ordinal 3 |
| `artifact_sha256` | `TEXT NOT NULL CHECK (length(artifact_sha256) = 64)` | The bundle the map rode in. **D-24 re-verifies the reloaded body against this and fails closed** |
| `request_id` | `TEXT NOT NULL` | The originating request for D-07's on-demand reload |
| `source_sha256` | `TEXT` | NULL when this index had no content (Pitfall 3) |
| `sources_verbatim` | `TEXT` | **The one target-controlled column.** NULL when `sources[i]` is itself null |
| `producibility` | `TEXT NOT NULL CHECK (producibility IN ('producible','gone','changed'))` | D-22/D-23 |
| `producibility_at` | `INTEGER` | When the outcome stuck |
| `recovered_at` | `INTEGER NOT NULL` | D-22's tombstone copy interpolates this date |

PRIMARY KEY `(project_id, map_sha256, source_index)`.

Indexes: `idx_source_sightings_artifact ON source_sightings (project_id, artifact_sha256, source_index)`
and `idx_sources_seen ON sources (project_id, first_seen_at, source_sha256)`, both ascending — SQLite
traverses an index in reverse for the opposite `ORDER BY`, so one direction serves both.

**What is NOT here, which is the mitigation:** no content column in any encoding, no BLOB, no untyped
column, no `id`, no `body`, no JSON blob, and no per-reason column. `sources_verbatim` is the FIRST
target-controlled string at rest since `observations.url`, and its allowlist justification will say
plainly that it is NOT redacted at write time (D-06 forbids it) and that its safety therefore rests
entirely on R1/R2 at render and on the O-08 display normaliser — a display control, not a storage
control.

**The cost D-09 accepts, restated so the approval is informed:** one row per recovered source under
NORMAL retention caps, no exemption. A 781-source map is 781 `sources` rows and 781
`source_sightings` rows against a `DEFAULT_RETENTION_MAX_ROWS` of 50,000, so a handful of large maps
consumes the budget and the operator meets eviction sooner here than on any other table. Phase 6's
D-25 footprint readout will show it.

**The one-way half:** reversing D-07 means adding a content column, which fires `schema.spec.ts` by
design and re-opens Phase 6's D-24 and its "DEPLOY-04 is satisfied by construction" claim.
