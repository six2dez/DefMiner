<objective>
The surface the phase exists for, and the most hostile render target this product has ever had.

Target-controlled bytes, at megabyte scale, in a component whose entire job is to display them
faithfully. D-18 (virtualise) and D-19 (no highlighting, plain monospace) keep that surface as small as
it can be while still delivering the feature, and R1's *text, never markup* is doing the load-bearing
work. Every rendering rule here is a security control with the same standing as the backend's.

Two upstream debts are discharged in this plan's own words. **O-07's fifth separation mechanism
genuinely breaks** — the drill-down renders the parent's analysis state and each source's producibility
in the same view, and there is no arrangement of D-21's drill-down in which that is false — so it is
REPLACED by four binding, testable requirements rather than exempted. And **R6 closes the one sink a
`sources` string could plausibly still reach**: the browser download name.

Output: the drill-down shell, the viewer with its four body states, the position strip, the
content-addressed filename, and the `Sources` column.

Complete the viewer's state machine, bound what it renders twice over, and close the filename sink.

**The four body states, mutually exclusive, each with its own copy row and no two collapsible:**

  - **Content** — the reload succeeded and the reloaded body's digest matched. The virtualised line
    list.
  - **Gone** — D-23 detected at open that the originating request is no longer retrievable; the outcome
    was written once on the backend and sticks. The D-22 tombstone SENTENCE in a padded block at Body
    role, interpolating only DefMiner-formatted values. The tree row carries the single word.
  - **Changed** — D-24's re-verify found the reloaded body's digest does not match; the target
    redeployed. The bundle-changed sentence, same shape. **FAIL CLOSED: the content is WITHHELD, never
    transparently re-derived from the new body.**
  - **Could not ask** — the derivation RPC failed, timed out or was not answered. The RPC-failure copy
    with Retry and Open Health, stating EXPLICITLY that the source has NOT been marked unavailable.

**Write the rule that outranks the table into the component, as a comment and as a test:** a failed
call is NEVER rendered as a tombstone and the frontend NEVER infers producibility. The component maps
the backend's four result arms one-to-one and derives nothing. A frontend that painted a timeout as
the gone state would be making a durable-looking claim from an absence of evidence.

**Record the fifth state that is NOT here**, so a reader does not look for it: a map that was refused,
truncated or malformed produces no source rows at all, which is the TREE's empty state and whose reason
lives in the evidence panel at the artifact level.

**The two bounds, each with its own visible marker:**

  - **The line-count cap** at `SOURCE_LINE_COUNT_MAX`. Over it, the first N lines render and the copy
    states the bound in words. Do not truncate silently.
  - **The per-line grapheme cap** through `forSourceLine`. A truncated line renders its marker inside
    the row, and the copy-full-line affordance reads the full line FROM THE FRONTEND STORE and writes
    it to the CLIPBOARD. The full untruncated line is never in the DOM, never in a title attribute and
    never in a data attribute.

**O-02, the no-line-structure case.** A file whose line count is 1 while its byte length is large is
MINIFIED CODE THE MAP DECLARED AS A SOURCE — real intelligence about the bundle, not a rendering
failure. It renders as ONE ROW, truncated, plus a visible degradation marker saying so in DefMiner's own
words. Nothing about the scroller changes.

**The legal empty file.** A zero-byte source is legal per spec and renders as a file with zero lines
plus a stated line count — not an error and not a tombstone. Three separate absent-content states
already exist and this is not one of them.

**`source-filename.ts` — R6.** A pure function taking the source's content digest and the display
label and returning `{first 16 hex characters of the digest}{extension}`, where the extension is
MATCHED — not derived — against a closed, DefMiner-authored allowlist of source-code extensions with a
plain-text fallback. **No byte of the target's string reaches the filename.** Export the allowlist as a
frozen array so its membership is one edit.

The save affordance in the viewer header downloads the content the viewer ALREADY HOLDS through the
shipped browser-download helper — the backend returns bytes and no path is sent, received or
