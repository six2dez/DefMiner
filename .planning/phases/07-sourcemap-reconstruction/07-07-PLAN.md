`packages/frontend/src/sourcemap/tree.ts` exports `buildSourceTree(rows)` returning a node forest.
Each node is `{ label, sourcesIndex, degraded, children }` and **`label` is NEVER the identity** — every
read that needs the real string goes back to the row by `sourcesIndex`.

**Step 1 — classify the shape, do not repair it.** Read a prefix kind off the verbatim string using
only `indexOf` / `startsWith` — never a pattern, because the ReDoS rule is a project rule and the
fixture cost is the same in a browser. Five shapes and five synthetic display roots: protocol-ish
(contains the scheme separator before any forward slash, or starts with a known scheme); absolute
POSIX; a drive-letter form; a UNC form; and relative. These are exactly the shapes SPIKE-12
enumerated, so the fixture set already exists.

**Step 2 — split on BOTH separators.** A Windows-authored entry uses backslashes and a
forward-slash-only split renders it as one enormous leaf. Display-only, and it cannot corrupt anything
because the verbatim string is untouched.

**Step 3 — resolve the current-directory and parent-directory segments FOR THE TREE ONLY, and never
above the root.** A climb that would pop past the root is CLAMPED AT THE ROOT AND MARKED — not
followed and not dropped. This is the one step where the traversal fixtures earn their keep: a
`webpack://app/src/../../secret.ts` entry must render as a node the operator can SEE, at a position
that is honest about the climb, and must never be silently rewritten as though the developer had
written the shorter path. Label the affected node with the count of climbs that went past the root; the
developer's real layout is the evidence D-06 exists to preserve and the climb is part of it.

**Step 4 — sanitise each SEGMENT through `forCellText`.** The text-only variant, for the measured
reason. This is what handles the RTL overrides, the NUL bytes and the 4 KB labels: the bidi strip, the
control strip and the grapheme truncation are R2 steps 1-3 and they already exist in the engine.

**Step 5 — disambiguate duplicate sibling labels BY POSITION, never by renaming.** Do NOT normalise
Unicode and do NOT case-fold. SPIKE-12 measured both mechanisms in the wild — an NFD and an NFC
spelling of the same visible name, and a case-only pair — and collapsing them would destroy two
genuinely distinct source files into one node. Siblings key on `(display label, sources index)`, so
duplicates render as separate nodes and each carries its index.

**Ordering:** by the map's own `sources` index within each parent. Deterministic, and it matches the
evidence — the order the developer's bundler declared. Never sorted, never sortable.

**Depth:** flatten to a visible-node list for the scroller. Indent is capped at eight levels; a node
deeper than eight holds the maximum indent and does not grow further, because an indent that could
grow without bound in a quarter-width column is an indent that eventually leaves no room for the label
the operator came to read.
