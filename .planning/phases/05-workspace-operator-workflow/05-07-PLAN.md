<objective>
Write the fixed literal-statement matrix, the row-value keyset cursor and the bounded candidate
window over the two shipped tables that hold real target-controlled bytes — then expose them as a
typed, versioned RPC surface that emits invalidation summaries and nothing else.

Purpose: `05-UI-SPEC.md` mandates server-side filtering and sorting with keyset pagination and bans
client-side sorting. `sql-discipline.spec.ts` permits only fixed literal statements with positional
binds. `05-RESEARCH.md § O-01` disqualified the two alternatives by execution rather than argument —
the null-guard predicate costs two million virtual-machine steps to return an empty page over a
two-hundred-thousand-row partition against twenty-four on a leading index, and an allowlisted
fragment builder is invisible to the gate entirely, so it could not earn an exemption, only create
an ungated surface. The matrix is what remains, and it is the shipped pattern: the observations
module already carries two complete literals chosen between, for exactly this reason.

Output: `reads.ts`, `api/spec.ts`, and the registration and event emit in `index.ts`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator filter and sort choice -> statement selection | The only place a user-supplied value could reach SQL; it selects between literals and never enters one |
| one SQLite file -> every Caido project | Every new statement needs its project predicate in the predicate, not in the select list |
| backend -> frontend event channel | What crosses here is the difference between a summary and a leak |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-32 | Tampering | filter or sort parameter reaching SQL | critical | mitigate | The fixed matrix means sort and filter select *between* literals, never *into* one; enforced statically by the widened gate including its fragment-composition rule (task 1) |
| T-05-33 | Denial of Service | a filter matching nothing walking a whole project partition on the single thread | high | mitigate | Bounded candidate window inside every filtered statement, with the equal-scanned-count-at-two-partition-sizes assertion proving selectivity independence (task 1) |
