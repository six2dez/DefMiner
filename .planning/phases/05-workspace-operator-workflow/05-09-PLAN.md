<objective>
Build the table surface: one shared shell carrying every state the design contract enumerates, two
concrete tables over the shipped artifacts and observations data, the degradation marking UI-09
requires, and the ten-thousand-row load backstop that cannot be signed off by inspection.

Purpose: this is the focal point of the whole workspace. The design contract puts the score-and-value
column pair at the top of the visual weight order because the product thesis is that signal quality
is high enough that the operator reads every finding — and it makes the fixed row height load-bearing
rather than cosmetic, because a wrapping cell degrades the recycling scroller off its fast path and
costs the responsiveness target outright.

Output: `InventoryTable.vue`, `StatusBadge.vue`, `PartialBanner.vue`, the two concrete tables, their
specs, the tab wiring, and `tests/frontend-load.spec.ts`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| target-controlled row value -> table cell -> DOM | Two of the columns on these tables carry bytes served by a possibly-hostile host; the observed URL is the genuine article |
| analysis completeness -> the numbers the operator reads | A count presented as a total when the analysis stopped early is a false claim the operator acts on |
| ten thousand rows -> the renderer | An unbounded resident set is a self-inflicted freeze on the surface the whole product is judged by |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-44 | Tampering | an observed URL rendered as markup or as a link destination | critical | mitigate | Every target-controlled cell goes through the display path from plan 05-05; the static gate reports a non-literal link-destination binding; no component here calls the engine pipeline directly (tasks 1, 2) |
| T-05-45 | Spoofing | a hostname column reversed by a bidi override, or a lookalike character read as the real one | high | mitigate | The display path strips bidi before truncation, and the mandatory monospace rule on the target-controlled column is what makes lookalike characters distinguishable at all (tasks 1, 2) |
| T-05-46 | Repudiation | an aggregate presented as a total when a contributing artifact stopped early | high | mitigate | The banner renders whenever any contributing artifact is not complete, states the floor in words, and the per-row badge is independent of it (task 2) |
| T-05-47 | Denial of Service | a multi-megabyte cell breaking row geometry or freezing the renderer | high | mitigate | Fixed row height with pre-formatted whitespace and hidden overflow, the cell cap, and the browser-driven backstop asserting measured row heights and elapsed time (tasks 1, 3) |
| T-05-48 | Denial of Service | an unbounded resident row set at ten thousand rows | high | mitigate | The recycling scroller at a fixed item size plus the store's window bound, asserted as a measured maximum in a real browser (tasks 1, 3) |
| T-05-49 | Information Disclosure | a revealed value rendered into a table cell and thereby into a screenshot | high | mitigate | Reveal is panel-only by design decision D1; no table component in this plan exposes a reveal affordance (tasks 1, 2) |
