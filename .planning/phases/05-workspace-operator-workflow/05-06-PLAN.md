<objective>
Add the fifth table — `audit` (STORE-08) — as a new forward migration step, extend the schema gate's
two exact sets to know about it, write the append-only single-statement writer, and make D-06's
retention exception visible in the sweep code rather than implicit.

Purpose: three of the seven actions this table records cannot be undone or cannot be unseen — a
projected Finding is permanent, a raw export leaves the tool in cleartext, a revealed value is a
disclosure — and the other four silently change what the operator is shown. An audit log that omits
the disclosures is not an audit log. D-06 settles that it is exempt from the retention age bound
and keeps only a raised row bound, because the questions it answers ("when did I project this
permanent Finding, and what did I export") are asked long after ninety days.

The same migration step also carries the direction-explicit keyset indexes plan 05-07's reads
depend on, because a mismatched index direction costs a temporary sort structure that plan 05-02
measured by contrast.

Output: schema step, gate extension, `audit.ts`, and a retention exception with its reason stated in
the file's own voice.
