written next year.

      to decide whether a given string is target-controlled, because that decision cannot be made
      statically and getting it wrong leaks a secret into a hover.

    - `HighlightSlices` given ranges out of ascending order, or overlapping, fails loudly in development rather than silently reordering or merging.

    imports `forDisplay`, `forEvidence`, `TABLE_CELL_MAX_GRAPHEMES` and

    Export `forCell(value)` and `forPanel(value)` as thin, named wrappers that bind the cap so a
    caller cannot pass the panel cap into a cell by accident, and `copyToClipboard(value)` which
    writes the full value to the clipboard and **never inserts it into the DOM** — that is the
    truncation affordance's whole mechanism, and it is why the affordance is a button rather than a
    hover.

    `HighlightSlices.vue` implements R1's highlighting rule: given the display text and a list of
    ascending non-overlapping ranges, slice into plain strings and render them into sibling
    elements, the match ones carrying a surface-toned background class. Three plain strings for one
    range, `2n+1` elements for `n` ranges. Never a markup string built by concatenation — that is the
    exact defect the rule exists to prevent, and task 1's `markup-string-construction` rule reports
    it if anyone tries.

    Add a development-mode precondition check that the supplied ranges are ascending, non-overlapping
    and within the display text's length; on violation, throw with a message naming the offending
    pair. Silently reordering would hide a backend defect on a surface whose correctness the operator
    triages on; and record in a comment that the offsets arrive in the backend's byte space while
    the display text has been grapheme-truncated, so the caller is responsible for supplying offsets
    into the *displayed* string — the two spaces are not interchangeable, and this is where a future
    off-by-a-grapheme defect would land.

    Every element rendered carries the monospace class, `white-space: pre` and `overflow: hidden`, so
    a value containing a newline cannot grow the fixed row and break the recycling scroller's
    geometry.

    Place no `title` attribute and no data attribute on anything in this module or component.
